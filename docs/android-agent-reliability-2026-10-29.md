## 与原 Git 项目的对比

## 定位问题的具体修复

1. `ScreenGeometry` 统一全屏物理尺寸，树节点中心、边界和点击采用相同的 0～1000 坐标系，包含状态栏与导航栏。
2. 屏幕信息增加完整资源 ID、归一化边界及屏幕尺寸；树节点上限从 45 调整为 90，过滤不可见、禁用、无有效边界的节点。
3. 支持 `Tap.params.resource_id`；文字/描述完整匹配优先于包含匹配。同名目标仍不唯一时返回可恢复错误，不再直接点击搜索到的第一个节点。
4. 文字点击不再提前隐藏键盘，避免在已选目标与实际点击之间改变页面布局。坐标回退限制在真实可见屏幕范围内。
5. 密码输入不再默认附带猜测式提交，避免一条 Type 隐式跳页后，下一次 Tap 落到另一个页面。
6. 模型响应返回时若前台应用或屏幕尺寸变化，不执行这条旧观察下的点击、输入或滑动，而是反馈原因让下一轮重新观察。
7. 反馈“手势已派发”与“业务目标已成功”之间的区别，要求模型使用新的截图验证结果。无法仅凭 dispatchGesture 成功证明按钮已经点中。

这些改动降低可确认的定位风险，但资源 ID 不唯一、WebView 无障碍信息缺失、图像识别错误仍可能出现，真实业务页面需要真机对比。

## JSON 与规划修复

- 本地修复只处理 JSON 字符串以外的数字漏逗号和尾逗号，不改写字符串里的数字空格、密码和文案；不猜测修补字符串内未转义引号。
- 本地解析失败后最多请求模型纠正两次，同一步、同一截图下完成，期间不会向设备发送动作；仍失败则停止该次运行。
- 补救输出的 plan 不合并进正常计划，避免格式纠错改变业务进度。
- 默认 prompt 约束 3～12 个稳定计划项和简短 think，要求沿用 text/id 更新进度，禁止把每次重试追加成新计划。
- 原始响应与补救响应完整保存在运行目录的 `model-步骤-尝试.json`，同时保存 Chat 的 finish_reason / Responses 的 status，便于判断是否截断。
- 历史 JSONL 改为结构化序列化，错误含换行或引号时仍可正确回读；不再把动作对应模型输出截成 4000 字符。
- 未额外开启供应商可能不支持的 JSON Schema 参数。若用户启用了自定义 system prompt，本次默认 prompt 修改不会覆盖它；执行器和补救逻辑依然生效。

## 失败后 5 分钟重试规则

- 任务编辑页新增“失败后 5 分钟自动重试一次”，默认开启，可按任务关闭。
- 适用于从任务中心或计划启动、绑定了任务 ID 的执行。没有模板归属的 `/agent/start` 请求不会擅自生成后台重试。
- 解析补救耗尽、模型调用错误、连续动作失败、达到步数上限及运行异常等结束后，从失败时刻起安排 300000 ms 后补跑一次；任务启动失败或因已有任务占用而跳过，也可进入一次补跑。
- 补跑再次失败不会继续无限重试。正常计划下一次触发或新的手动运行建立新的运行周期。
- 待重试时间、重试次数、来源和恢复线索写入任务存储；正常计划与重试共用现有 AlarmManager 机制，选择更早的触发时间，保留周期计划。
- 单次计划即使在原触发时已经清除，也能注册失败补跑。
- 重试到点执行器仍忙时延后 5 分钟，不再拉起页面干扰正在运行的任务，也不增加重试次数。
- 成功、手动停止、取消待重试、删除、编辑和暂停计划会撤销对应旧重试。编辑增加任务修订号，旧执行结束后不得给新版本重新安排重试。
- 当前处于暂停状态的任务不自动补跑。卡片显示待重试时间，并提供“取消本次自动重试”。
- 重试从当前界面重新观察，带入上次计划与 Notes 作为核对线索；要求先确认已有提交是否成功，不盲目从登录或提交步骤重新开始。这是恢复指导，不是业务应用内部的幂等保证。
- 重试属于定时执行，保留上一版“不弹完成弹窗”的行为，运行结果仍进历史。

此外，任务归属在启动时固定，完成时不再使用可能已变化的 selectedId；旧运行结束回调也会核对 runId，避免影响新的运行。

- `:app:testDebugUnitTest` 共 34 项，全部通过，0 失败、0 错误、0 跳过。

- Robolectric 测试覆盖真实 ManagerStore 的 SharedPreferences 写入和重新创建、AlarmManager 闹钟注册与撤销、编辑/暂停/删除/占用延后、一次补跑额度，以及长文本、引号和换行的历史回读。它是 Android 本地模拟环境测试，不是手机实测或真实重启测试。
- `lintDebug` 仍有 4 个已知错误：两个 MissingPermission、AppLauncher 的 WrongConstant、清单中的 QueryAllPackagesPermission。本次未新增静态检查错误；没有为了消除报错改动这些原有逻辑。

运行测试需要 JDK 17 和已有 Android SDK：

```sh
./gradlew :app:testDebugUnitTest :app:assembleDebug
```

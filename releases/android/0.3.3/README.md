# Android 0.3.3（构建 10）：飞书接收诊断

## 变化

- 在配置页“飞书远程控制”的连接状态下显示最近 12 条诊断，可长按选择复制。
- 收到消息时显示实际发送者 ou_ 和会话 oc_，帮助核对白名单。未授权消息仍不执行、不回复。
- 区分用户白名单、群白名单、未 @当前机器人、非文本、非半角 / 命令、过期/手机时间异常、应用不匹配等拒绝原因。
- 显示命令持久接收、重复消息去重、回复发送成功或失败；连接/发送错误仅显示已知类别和数字码。
- 补充“开关修改后必须保存才生效”的界面提示；凭证验证期间显示实际阶段。
- 不改变已有命令、授权规则、去重、任务执行及重试。延续 0.3.2：结束后仅保持页面或返回 One Agent，不关闭目标 App。

## 安装后定位当前问题

1. 覆盖安装 APK，不要卸载或清除数据。顶部应显示 0.3.3（构建 10）。
2. 打开配置页，点击“保存远程设置并重新连接”，等待长连接建立。
3. 私聊与手机 App ID 对应的机器人，发送新的 /帮助。
4. 回到手机查看最近诊断：
   - “收到消息事件”后“用户白名单”：把收到的 ou_ 与允许用户字段逐字核对，不能填机器人 ID 或其他应用下的用户 ID。
   - 群白名单或未 @：核对收到的 oc_；仅群聊需要群白名单与实际 @当前机器人。
   - 消息过期/时间异常：检查手机日期时间及指令有效期，修正后发新消息。
   - “命令已校验并持久接收”后“回复失败”：提供错误码，继续查发送权限或网络。
   - “回复已发送”：检查对应机器人会话；仅表示飞书 API 已接受，不代表人工已读。
   - 始终没有“收到消息事件”：仍需查订阅/发布、是否其他客户端消费同一应用长连接、传输或接收处理。不能仅凭后台 SUCCESS 认定命令已通过本机校验。
5. 将手机诊断文字或截图反馈。不要提供密钥、令牌或原始任务密码。

诊断仅保留在本次进程内，重启后清空；不写入消息正文、任务正文、App Secret、令牌或连接 URL。显示的用户与会话 ID 仅用于本机核对，不自动加入白名单，不回传第三方。
